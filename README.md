# Sleep Disorder Analysis

## Overview
This project analyzes sleep disorder data to identify patterns and relationships between lifestyle factors and sleep health.

## Tools Used
- Python (Pandas, NumPy, Matplotlib)

## Key Tasks
- Cleaned and processed  dataset  
- Performed exploratory data analysis (EDA)  
- Visualized trends and patterns  
- Identified correlations affecting sleep disorders  

## Insights
- Lifestyle factors such as stress and activity levels impact sleep quality  
- Data can support predictive health analysis
